# GENERAL DEVELOPMENT SKILLS

# 1. Git

Roadmap yêu cầu Git và các Git hosting như GitHub, GitLab, Bitbucket. 

### Định nghĩa

Git là **distributed version control system** dùng để quản lý lịch sử thay đổi source code.

### Mental model

```text
Working Directory
       ↓ git add
Staging Area
       ↓ git commit
Local Repository
       ↓ git push
Remote Repository
```

### Command phải biết

```bash
git init
git clone

git status

git add .
git commit -m "message"

git log
git diff

git branch
git switch
git switch -c feature/login

git merge
git rebase

git fetch
git pull
git push

git stash

git reset
git revert
```

### Branch

Ví dụ:

```text
main
 ├── feature/login
 ├── feature/register
 └── fix/user-api
```

Thông thường:

```bash
git switch -c feature/login
```

→ code → commit → push → Pull/Merge Request.

### Merge vs Rebase

**Merge**

```text
A---B---C
     \   \
      D---M
```

Giữ lịch sử branch.

**Rebase**

```text
A---B---C---D'
```

Đưa commit của branch lên trên base mới.

### `reset` vs `revert`

**reset**

> Di chuyển HEAD/lịch sử local.

**revert**

> Tạo commit mới để đảo ngược commit cũ.

⚡ Đừng tùy tiện `reset --hard` trên branch shared.

# 2. HTTP / HTTPS

Roadmap liệt kê HTTP/HTTPS như một kiến thức nền trước ASP.NET Core. 

### HTTP là gì?

HTTP là protocol để client và server giao tiếp.

```text
Client
  │
  │ HTTP Request
  ↓
Server
  │
  │ HTTP Response
  ↓
Client
```

### Request

```http
POST /api/users HTTP/1.1
Content-Type: application/json

{
  "name": "Trung"
}
```

Gồm:

```text
Method
URL
Headers
Body
```

### HTTP Methods

| Method | Ý nghĩa                 |
| ------ | ----------------------- |
| GET    | lấy dữ liệu             |
| POST   | tạo                     |
| PUT    | thay thế/update toàn bộ |
| PATCH  | update một phần         |
| DELETE | xóa                     |

### Status Code

**2xx**

```text
200 OK
201 Created
204 No Content
```

**3xx**

```text
301
302
304
```

**4xx**

```text
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
409 Conflict
422 Unprocessable Entity
```

**5xx**

```text
500 Internal Server Error
502 Bad Gateway
503 Service Unavailable
```

### HTTPS

```text
HTTP
  +
TLS
  ↓
HTTPS
```

HTTPS giúp:

* Encryption
* Authentication
* Integrity

### REST cần hiểu

```text
GET    /users
GET    /users/123
POST   /users
PUT    /users/123
DELETE /users/123
```

⚡ Khi làm ASP.NET Web API, HTTP là kiến thức **cực kỳ quan trọng**, không chỉ là biết các method.
